# mind2slide
Вы готовитесь к выступлению и структурируете свои мысли в виде иерархического списка. По мере роста структуры, вам нужна возможность увидеть ваши мысли вцелом и в этом вам может помочь ментальная карты (mindmap). Когда мыслей наберётся достаточное количество, то можно будет распределять их по слайдам презентации.
Используемые библиотеки
* построение и отображение ментальной карты [jsMind](https://jsmind.online/#sample)
* демонстрация последовательности слайдов [RevealJS](https://revealjs.com/)
